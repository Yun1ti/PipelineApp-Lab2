# PipelineApp

Консольное приложение на C++17 для работы с объектами трубопроводного транспорта газа: трубами и компрессорными станциями (КС).

## Возможности

1. Добавить трубу
2. Добавить КС
3. Просмотр всех объектов
4. Редактировать трубу (признак «в ремонте»)
5. Редактировать КС (запуск и останов цеха)
6. Удалить трубу
7. Удалить КС
8. Поиск труб (по названию, по признаку «в ремонте») и пакетное редактирование: изменение статуса или удаление всех найденных или выбранных труб
9. Поиск КС (по названию, по проценту незадействованных цехов)
10. Сохранить в файл (имя задаёт пользователь)
11. Загрузить из файла (имя задаёт пользователь)
0. Выход

У каждого объекта есть уникальный ID. После удаления ID не используются повторно, после загрузки нумерация продолжается с максимального ID в файле.

## Логирование

Всё, что пользователь вводит с клавиатуры, записывается в один файл `log.txt` в папке программы: одна строка ввода — одна строка лога, без пояснений. При каждом новом запуске файл перезаписывается.

Чтобы воспроизвести сеанс, передайте лог программе аргументом. Программа выполнит все действия из файла и покажет введённые значения на экране; сам `log.txt` при этом не изменяется.

```powershell
.\PipelineApp.exe log.txt
```

## Сборка и запуск (PowerShell)

Нужна Visual Studio с компонентом «Разработка классических приложений на C++».

```powershell
.\build.ps1             # сборка PipelineApp.exe
.\PipelineApp.exe       # обычный запуск, ввод пишется в log.txt
.\PipelineApp.exe log.txt  # воспроизведение действий из log.txt
```

Если PowerShell запрещает запуск скриптов: `powershell -ExecutionPolicy Bypass -File .\build.ps1`.

## Отладка в VS Code

Нужно расширение C/C++ (ms-vscode.cpptools). Откройте папку проекта, на вкладке «Запуск и отладка» (F5) выберите конфигурацию:

- **Run (input is logged to log.txt)** — обычный запуск под отладчиком;
- **Replay log.txt** — запуск под отладчиком с воспроизведением действий из `log.txt` (можно ставить точки останова).

Перед запуском проект собирается автоматически (задача `build` в `.vscode/tasks.json`).

## Структура

- `InputReader` — ввод с проверкой корректности, запись в лог и воспроизведение
- `StreamUtils` — разбор чисел и строк из потоков
- `Pipe`, `CompressorStation` — сущности
- `ObjectRegistry<T>` — шаблонное хранилище объектов с уникальными ID и поиском по фильтру
- `PipelineNetwork` — все трубы и КС, сохранение и загрузка
- `ConsoleMenu` — меню и действия пользователя
