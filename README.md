# PipelineApp

Консольное приложение, описывающее базовые сущности трубопроводного транспорта газа: трубу и компрессорную станцию (КС).

## Возможности

1. Добавить трубу
2. Добавить КС
3. Просмотр всех объектов
4. Редактировать трубу (признак «в ремонте»)
5. Редактировать КС (запуск и останов цеха)
6. Сохранить в файл `pipeline_data.txt`
7. Загрузить из файла
0. Выход

Весь ввод проверяется: неверные числа, выход за допустимый диапазон, пустые строки и повреждённый файл данных не приводят к сбою программы.

## Сборка

```
cmake -S . -B build
cmake --build build
```

Либо открыть папку проекта в Visual Studio (поддержка CMake).
